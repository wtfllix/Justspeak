# M0 实机验收规程（尚未执行）

M0 退出要求来自 PRD §20：两台 Windows 电脑、双向语音连续一小时、麦克风选择、断开重连。合成音频或同机双客户端不替代此项。

## 每次测试必须记录

记录源码 SHA/文件校验值、构建时间、Windows 版本、CPU/逻辑核数、WebView2 版本、Rust/LiveKit 版本、耳机/USB/蓝牙型号、服务器区域/配置、网络类型、参与者、开始结束 UTC 时间。保存实际观察和原始日志；不采集 Token、连接码或语音内容，录音须双方主动同意。

## 两机一小时

1. 按 README 部署 TLS 测试服务器，在两台 Windows 构建桌面端。
2. 各选不同昵称与真实麦克风，使用管理员分发的内测连接码连接同一服务。
3. 两边均手动开麦，相互说话并确认听到对方。确认成员列表和订阅数来自真实会话。
4. 连续通话 60 分钟，每 5 分钟双方说话确认，记录无声、回声、断续与崩溃时间线。请保持耳机，另开外放测试单独记录 AEC。
5. 在一台机器选择第二个麦克风，确认先静音，手动开麦后对方听到新设备。
6. 主动断开，确认 OS 麦克风采集停止、另一端成员离开。再输入连接码重新连接。
7. 断网 5/15/60 秒后恢复，记录实际恢复时间。SDK 重连时先静音，恢复后需手动开麦；若终止则点断开后重新连接。
8. 连接期间取消，等候超过 30 秒，确认没有迟到入房和采集。快速重复连接/取消，确认最多一个房间发布。
9. 拔出麦克风、拒绝权限、无播放设备、错误连接码、错误 TLS、UDP 阻断分别测试。设备热插拔仍属 M3 完整验证范围。
10. 100%/150%/200% DPI 测窄窗及设置展开，确认不会中断通话。

## 性能

使用 Release exe，启动稳定 5 分钟后，使用 PID 指向 xxspeak-desktop.exe（勿用 npm/cargo PID）：

```powershell
powershell -File scripts/measure-windows.ps1 -ClientPid 1234 -Seconds 300 -Output evidence/idle
powershell -File scripts/measure-windows.ps1 -ClientPid 1234 -Seconds 3600 -Output evidence/two-party
```

脚本采当前子进程树（包含 WebView2）私有工作集与按全机逻辑核归一的 CPU；报告真实采样时间、p50/峰值内存和均值/p95 CPU。目标值不是结果。脚本未在 Windows 验证，使用前核对 CIM 计数器与进程树完整性。

端到端延迟需声学回环/同步采集测口到耳；不能用 RTT 代替。服务端带宽需网卡计数器或外部监控测实际字节。四人三小时游戏、标准/AI 对比和全局 PTT 留给 M1/M3/M5。
